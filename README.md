# THE DANGANRONPA ARCHIVE

Arquivo de fã não oficial em português, concebido como uma investigação digital classificada — não como uma wiki convencional.

**Site:** https://otaviopasseighteen-maker.github.io/DANGARONPA/

## Experiência
- Tela inicial com quatro arquivos de jogo distintos.
- Cada jogo tem suas próprias abas de personagens, história/casos, execuções e inteligência.
- Dossiês individuais de personagens com talento, função, resumo e arte quando disponível nos dados.
- História com botão explícito para revelar ou ocultar detalhes com spoilers.
- Registros de execução abrem em um dossiê; vídeos externos só são incorporados quando a URL permite.
- Pesquisa global atravessa os personagens de todos os jogos.
- Layout responsivo, diálogos nativos, suporte a preferência de movimento reduzido e identidade visual inspirada em arquivos confidenciais.

## Jogos
- Danganronpa: Trigger Happy Havoc
- Danganronpa 2: Goodbye Despair
- Danganronpa Another Episode: Ultra Despair Girls
- Danganronpa V3: Killing Harmony

## Tecnologias
HTML, CSS, JavaScript e dados JSON. Sem etapa de build ou framework, para manter a implantação simples no GitHub Pages.

## Pré-visualização local
Como o site carrega JSON com `fetch`, use um servidor local em vez de abrir o HTML diretamente com `file://`. Exemplo: `python -m http.server` na pasta do repositório e acesse `http://localhost:8000`.

## Nota de precisão
O site exibe as informações atualmente registradas em `data/`. Imagens e vídeos externos dependem de seus provedores e podem mudar. Lacunas ficam sinalizadas em vez de serem preenchidas com fatos inventados. Projeto de fã sem afiliação com Spike Chunsoft ou detentores dos direitos.
